🔧 TROUBLESHOOTING

PROBLEM: 🔴 Disconnected Badge
SOLUTION:
  1. Check all 4 secrets are set in Replit
  2. Verify spelling: DB_HOST_STELLARRISK (not typos)
  3. Make sure 192.168.102.245 is accessible from Replit
  
  → If still fails, may need network whitelist from database admin


PROBLEM: Excel File Not Found Error
SOLUTION:
  1. Verify file name: FUT-01-41-VAR-CORREL.xlsx (exact spelling)
  2. Check it's in Replit root directory (alongside app.py)
  3. File size should be ~500KB
  4. Re-upload if needed


PROBLEM: Blank Screen / Stuck Spinner
SOLUTION:
  1. Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
  2. Clear browser cache
  3. Try different browser
  4. Try incognito/private window


PROBLEM: App loads but says "Cannot connect to API"
SOLUTION:
  1. Click Replit Logs (bottom right) - look for Python errors
  2. Check if Flask started (should say "Running on...")
  3. Verify requirements.txt installed (click Run again)
